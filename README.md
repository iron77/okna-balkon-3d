# Okna balkonowe 3D

Model 3D dwóch drewnianych okien balkonowych (okno w skrzyni i okno większe) z kawałkiem budynku, do obracania w przeglądarce:
https://iron77.github.io/okna-balkon-3d/

- przekroje i rzut z rysunku technicznego okien (DWG),
- daszek ze stalowych krokwi, otwieranie skrzydeł (przycisk albo klik w klamkę),
- roleta ZIP w trzech położeniach i moskitiery NEHER do wyboru.

Strona jest jednym plikiem `index.html`; biblioteka three.js wczytuje się z cdn.jsdelivr.net (potrzebny internet).
Plik powstaje w projekcie rysunku (`tools/model3d.py`) – tu jest tylko gotowa strona.
